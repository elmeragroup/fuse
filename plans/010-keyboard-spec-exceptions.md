## Why this matters

The general accessibility specification promises that keyboard behavior "inherits base-ui verbatim" and that Escape dismisses the topmost open overlay only. Two wrappers deliberately change a Base UI default and are covered by browser tests: DropdownMenu.Sub closes the whole menu tree on Escape (Base UI would close only the submenu), and Tabs.List activates a tab when arrow keys move focus to it (Base UI would wait for Enter or Space). The spec is normative, so a future contributor reading it could "fix" these tested defaults back to Base UI behavior. Correct the general contract so it describes what ships.
