  The canonical labeling mechanism. `Field.Root` wires `id`/`htmlFor`,
  `aria-describedby` for description and error, and error announcement, so every control
  composed under it gets its accessible name from `Field.Label`.

No control invents its own label wiring. If an input-like component needs a visible
label, a description or an error, it is composed under `Field.Root`.
