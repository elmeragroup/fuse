<Prose>

The five faces are separate components, not a `face` variant axis — that keeps
per-face tree-shaking and matches the app call sites that consume `Emoji.PartyingFace`.
Named exports (`SlightlySmilingFace`, …) exist for the same reason; the `Emoji`
namespace stays canonical.

There is no default size. Consumers size with `className` (`size-4` / `size-5` /
`size-8`). Hex fills are illustration artwork and do not follow theme tokens.

Without `label` the svg is `aria-hidden` so it is not announced next to adjacent
text. With `label` it becomes `role="img"`. The component ships no default copy —
`label` is already localized at the call site.

Graphics remain CC BY 4.0 Twemoji artwork (U+1F641, U+1F642, U+1F610, U+1F62D,
U+1F973). Attribution ships in the published tarball.

</Prose>
