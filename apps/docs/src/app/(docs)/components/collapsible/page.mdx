<Prose>

Collapsible is a visually unstyled passthrough over `@base-ui/react/collapsible`. The
wrappers add `data-slot` attributes and the canonical `focusRing` on `Trigger` — nothing
else. Style via `className` or `render`. Height animation uses
`--collapsible-panel-height` on the panel, for example
`h-0 overflow-hidden transition-[height] data-open:h-(--collapsible-panel-height)`.

Ungrouped `Disclosure` usage migrates here: `defaultExpanded` → `defaultOpen`,
`isExpanded` → `open`, `onExpandedChange` → `onOpenChange`, `shouldUnmountOnCollapse` →
`!keepMounted`. Grouped usage migrates to Accordion.

</Prose>
