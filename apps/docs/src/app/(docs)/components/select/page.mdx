---
title: Select
lede: >
  A combobox over base-ui Select. The trigger carries a `data-size` sm|default axis;
  the popup portals into the nearest ThemeScope and, by default, aligns the selected
  item over the trigger.

<Prose>

Positioner props (`side`, `align`, `sideOffset`, `alignOffset`, `alignItemWithTrigger`) and
`container` surface on `Select.Content`. Alignment with the trigger is on by default and
suppresses the entrance animation so the popup appears in place. Portal, Positioner and
Popup stay unexported — `container` on Content is the only portal-control surface.

Trigger `size` is a control-box axis: `"default"` reads `--control-h-md`, `"sm"` reads
`--control-h-sm`. Invalid chrome uses `error` tokens; the trigger surface is `bg-card`.

</Prose>
