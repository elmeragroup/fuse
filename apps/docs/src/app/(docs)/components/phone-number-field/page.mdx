<Prose>

The country trigger is a `role="button"` so the Field label never bleeds onto it;
`selectCountryLabel` / `searchCountriesLabel` / `noCountriesFoundText` default to the
four-locale dictionary and win when passed. Locale comes from
`ElmeraGroupUiProvider` only — there is no `locale` prop.

Forms submit the hidden `name` input (E.164 by default). The visible input is named
`${name}-display-value` and holds the formatted display string. `Flag` and
`usePhoneNumberFieldState` stay package-private. The picker is `getCountries(metadata)`
intersected with packaged flag assets, minus the product exclusion set — `AC`, `BQ`,
`EH`, and `TA` never appear.

</Prose>
