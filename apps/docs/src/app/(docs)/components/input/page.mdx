<Prose>

`filter="numeric"` keeps digits only, whether they are typed, pasted or autofilled. On text-like input types it counts `maxLength` in digits, so a pasted number with spaces fits whole; the API reference lists the paths where the browser's own length handling still applies. `TextField` and `InputGroup.Input` take the same prop.
