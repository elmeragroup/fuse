<Prose>

`AlertDialog` is not shadcn's compound AlertDialog and not base-ui's AlertDialog primitive.
It reuses Dialog's popup, header, footer and title, stamps `role="alertdialog"`, and keeps
the confirm copy on `AlertDialog.Content` — title, body, action and cancel. The body is a
real `Dialog.Description`, so screen readers hear the consequence text through
`aria-describedby`.

There is no corner close button: an alert dialog must be answered. Cancel always closes;
the action button closes only when `isAutomaticallyCloseOnActionEnabled` is set, so async
flows can wait for success. Cancel copy comes from `alertDialog.cancel` unless `cancelLabel`
overrides it.

</Prose>
