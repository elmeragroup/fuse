A card pads its sections, and spaces them, with a surface tier. The default size takes the medium tier, 16px comfortable and 12px dense, which Items and Accordion items pad with too, so the text in a card starts on the same edge as theirs. `size="lg"` takes the large tier, 24px comfortable and 16px dense, for a card that holds long prose or acts as a page's main panel. A card nested in a large card takes its own size.

A card draws its 1px edge in the theme's `--card-border`. Internal themes draw it in `--border`. External themes draw no edge, so a white card stands on the page tint by its fill and shadow, and a card on a card-coloured surface, such as a nested card, has no outline. A border colour class on the card still wins. To change the edge, override `--card-border` on the `ThemeScope` or on any element around the cards.

A card can be split into stacked sections of equal weight with `Card.Section`. Each section pads every side with the card's tier, so it follows the card's `size`, and a 1px line in the theme's `--card-section-divider` runs between sections from edge to edge. Internal themes draw the line in `--border`, and external themes in the page tint, `--background`, so the card reads as split into segments. The first and last sections round with the card's corners, so a fill or a hover fill follows them. A `Card.SectionMedia` before the content makes the section a two-column grid with the icon centred beside the content; wrap the content in one element.

`render` makes a whole section a button or a link. It keeps its native semantics, takes a hover fill and a pointer cursor, and draws its focus ring inside its own edges, so the sections around it cannot cover it. Put no other control inside it.
