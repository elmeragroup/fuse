A card pads its sections, and spaces them, with a surface tier. The default size takes the large tier for content: a usage figure, a chart, a description. `size="sm"` takes the medium tier, 16px comfortable and 12px dense, for a card that holds a stack of short rows, such as an order summary, a receipt or a price box. Use it for a card beside selection items, Items or Accordion items, so the text in the card starts on the same edge as the text above it. A card nested in a small card takes its own size.

<Demo slug="card" id="sizes" title="Sizes" file="card-sizes.tsx">

</Demo>

A card draws its 1px edge in the theme's `--card-border`. Internal themes draw it in `--border`. External themes draw no edge, so a white card stands on the page tint by its fill and shadow, and a card on a card-coloured surface, such as a nested card, has no outline. A border colour class on the card still wins. To change the edge, override `--card-border` on the `ThemeScope` or on any element around the cards.
