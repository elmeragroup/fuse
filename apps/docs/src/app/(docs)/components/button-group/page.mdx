<Prose>

`ButtonGroup.Root` is a `div role="group"` — it does not provide roving focus. Tab moves
between child buttons; arrow keys do not. Name the group with `aria-label` or
`aria-labelledby` when the cluster needs an accessible name.

Children join the silhouette by emitting `data-slot`. That is why `ButtonGroup.Separator`
wraps the canonical library Separator instead of a slotless hairline, and why
`ButtonGroup.Text` stamps `data-slot="button-group-text"` through `useRender` `state`.
`orientation` defaults to `"horizontal"` so `data-orientation` is always present.
`ButtonGroup.Separator` flips that default to `"vertical"` — a horizontal group needs a
vertical hairline.

The public `buttonGroupVariants` recipe is the orientation axis other surfaces can borrow.
`ButtonGroup.Text` is the library's `useRender` convention exemplar: pass `render={<label
htmlFor=… />}` when the affix labels an adjacent input.

</Prose>
