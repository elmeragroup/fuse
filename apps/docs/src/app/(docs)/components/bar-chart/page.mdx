<ComponentIntro slug="bar-chart" />

<Prose>

The chart entry is a preview. Its names and props can change until Fuse's first stable release. `BarChart` is the same component as `Chart`. A bar fills its band less a 25 % gap, series that share a `stack` id stack in one column, and `BarChart.BarGroup` sets series side by side. Every bar is its own SVG element up to 100 slots, and above that each series draws one path. Bars draw in pixels once the browser measures the plot, so they land on whole device pixels at any width and zoom.

</Prose>

## Server components

<Prose>

A chart whose props are all plain data needs no `"use client"` line. This demo is a server component, so the server writes the figure, the axis labels and the table into the page's HTML, and the browser loads only the chart's own parts. The plot shows a skeleton until the browser measures it and draws the bars, and the plot keeps its height, so nothing around it shifts. A demo that reads a hook or passes a function, such as the capacity step's tooltip, stays a client module.

</Prose>

## Updates

<Demo slug="bar-chart" id="update" title="Data updates" file="bar-chart-update.tsx">
  <BarChartUpdate />
</Demo>

<Prose>

A data update moves each bar that stays to its new geometry over 480 ms, fades in the bars it adds and drops the bars that leave. A second update during the move starts from where each bar is drawn. A change of `xRange` alone snaps, and reduced motion snaps every update.

</Prose>

A Bar can wait behind its own Suspense boundary. When the server streams it in, it hydrates and draws its bars at rest. When it mounts in the browser after the chart, it snaps to its geometry and skips the entrance.

## Keyboard

<Prose>

The plot is one tab stop. The legend toggle group and the table's button add one each.

| Where               | Keys                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chart               | ArrowRight and ArrowLeft move one slot. PageDown and PageUp move a tenth of the window's slots, at least one. Home and End go to the window's first and last slot. ArrowDown and ArrowUp move the series focus. Enter and Space select the focused series while a legend toggle group is mounted, and pin the tooltip otherwise. Escape hides the tooltip and keeps focus, and a second Escape passes on. |
| Horizontal bars     | ArrowDown and ArrowUp move between categories, and ArrowRight and ArrowLeft move the series focus.                                                                                                                                                                                                                                                                                                        |
| Legend toggle group | Tab enters at the pressed toggle or the first. The arrows move, and Enter or Space presses a toggle. Pressing the pressed toggle clears the selection.                                                                                                                                                                                                                                                    |
| Table               | The table's button and the page buttons are native buttons. The button moves focus to the table, which never joins the Tab order.                                                                                                                                                                                                                                                                         |

</Prose>
