<Prose>

`Attachment.Root` holds one file: `Attachment.Media` with an icon or a picture, `Attachment.Content` with the `Attachment.Title` and `Attachment.Description`, and `Attachment.Actions` with one `Attachment.Action` per action. Fuse shows the file and its state. Picking files and uploading them stay in your app, which sets the root's `state` as the upload moves on.

</Prose>

## Image

`variant="image"` on the media frames an `img` in a square, which the image fills and crops to. `orientation="vertical"` stacks a tile with the media on top, and its actions float in the media's top end corner on a `secondary` fill, so they stay visible on any photo. For another shape, put an `Attachment.AspectRatio` inside the media with one of the [AspectRatio](/components/aspect-ratio) ratios.

</Prose>

## States

`state` takes `idle`, `uploading`, `processing`, `error` or `done`, and defaults to `done`. `idle` dashes the border. `uploading` and `processing` sweep a highlight across the title and dim image media, and the title stays still under reduced motion. `error` tints the border, the media and the description with the error role. The state only styles the attachment, so write it in words in `Attachment.Description`.

</Prose>

## Group

`Attachment.Group` lays attachments out in one row that scrolls sideways and snaps to each attachment. An edge fades while more attachments lie past it. The group is a list, and each root inside it is a list item. In a right-to-left app, wrap the app in Base UI's `DirectionProvider` as well as setting `dir`, since Base UI measures the scrolled edges from it.

</Prose>

## Trigger

`Attachment.Trigger` turns the whole attachment into one control that opens a preview or a link. It covers the attachment under its actions, so a click on an action never reaches it. It renders a `button`. Compose it with a dialog through `<Dialog.Trigger render={<Attachment.Trigger aria-label="…" />} />`, or make it a link with `render={<a href="…" />}`. Place it before `Attachment.Actions`, so it comes first in tab order.

</Prose>

## Accessibility

- **Name icon-only actions.** Give each `Attachment.Action` an `aria-label` that names the action and the file, such as "Remove floor-plan.pdf". Its type requires one.
- **Name the trigger.** `Attachment.Trigger` holds no text, so its `aria-label` says what activating it does, such as "Preview inspection-report.pdf".
- **Say why an upload failed.** The error state is a colour. Put the reason in `Attachment.Description`, such as "Upload failed. The file is over 10 MB."
- **Name the group.** Give `Attachment.Group` an `aria-label` or `aria-labelledby`. It names the list.

</Prose>
