Enter calls `onSubmit` with the value. Without `onSubmit`, Enter submits the surrounding form, as in any
text input. Escape empties a field that holds text and stops there, so a `Dialog` or `Sheet` around the
field stays open; on an empty field it closes them as usual. The clear button shows while the field holds
text. It is out of the tab order, and pressing it keeps focus and the on-screen keyboard on the input.

Inside a `Form`, the field submits its value under its `name`, shows the error the `Form` holds under that
name, and clears it on an edit or a clear.
