<Prose>

`UiProviders` is the quarantined convenience at `@elmeragroup/ui/react-aria/ui-providers`.
It requires `children`, a function-valued `navigate`, and a `SupportedLocale`. The
anatomy is `ElmeraGroupUiProvider` → RAC `I18nProvider` → RAC `RouterProvider` →
children. Dictionary strings still come from the permanent `/theme` provider;
RAC date and link surfaces read the same locale and the app router instead of
`navigator.language` or a full navigation.

When the react-aria tier retires, delete `UiProviders`. Keep
`ElmeraGroupUiProvider` from `@elmeragroup/ui/theme`. Do not nest both locale
providers.

</Prose>
