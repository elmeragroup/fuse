## Usage

{/* prettier-ignore */}
```tsx
import { Chart } from "@elmeragroup/fuse/chart";
import "@elmeragroup/fuse/chart.css";

<Chart.Root data={data} config={config} xKey="month" aria-label="Usage per month">
  <Chart.YAxis />
  <Chart.XAxis />
  <Chart.Bar dataKey="kwh" />
  <Chart.Tooltip />
  <Chart.Table />
</Chart.Root>
```

## Composition

<Prose>

`Chart.Root` reads every series from `config` and draws its children in the order you write them, so write the parts in paint order. Bars, lines and areas in one Root share its x axis and one value axis. To give series of different units their own value axis, put each set in a `Chart.Panel`. The Panels stack as rows over Root's x axis and share its tooltip, legend and table. `BarChart`, `LineChart` and `AreaChart` are `Chart` under other names, so their parts mix in one Root. For a numeric x axis, use [`ScatterChart`](/components/scatter-chart).

</Prose>
