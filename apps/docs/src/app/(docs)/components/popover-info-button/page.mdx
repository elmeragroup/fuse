<Prose>

The trigger is a public `Button` (`ghost` / `icon-sm` by default) merged onto
`Popover.Trigger` through the render slot — there is no nested button. `children`
become the popover body; placement is fixed at `side="right"` with `sideOffset={8}`
and `showArrow`. `contentSize` only changes the content max-width (`default` is
`max-w-md`).

The icon-only trigger is named by `label`, which defaults to the four-locale
`popoverInfoButton.moreInformation` dictionary. Locale comes from
`ElmeraGroupUiProvider` only. `container` forwards to `Popover.Content` and follows
the overlay portal contract (nearest `ThemeScope`, never `document.body`).

</Prose>
