## Usage

{/* prettier-ignore */}
```tsx
import { PopoverInfoButton } from "@elmeragroup/fuse/popover-info-button";

<PopoverInfoButton label="About grid rent">
  The grid rent is the fee you pay for using the electricity grid.
</PopoverInfoButton>
```
