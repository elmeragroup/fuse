The body flows inline content, such as a bold word or a link, as one paragraph, so translated rich
text needs no wrapper. Consecutive blocks, such as two paragraphs, are spaced apart.

`label` names both the button and the popover it opens, so prefer a specific label such as
"About grid rent" over the default "More information". A `Popover.Title` in the content names the
popover instead.
