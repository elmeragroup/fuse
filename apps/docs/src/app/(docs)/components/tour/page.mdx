## Usage

{/* prettier-ignore */}
```tsx
import { Tour, defineTour, useTour } from "@elmeragroup/fuse/tour";

const welcome = defineTour({ id: "welcome", steps: ["usage", "price"] });

<Tour.Provider>
  <Tour.Target tour={welcome} step="usage" title="Usage this month">412 kWh</Tour.Target>
  <Tour.Target tour={welcome} step="price" title="Your price">1.42 kr per kWh</Tour.Target>
  <Tour.Popup tour={welcome}>
    <Tour.Header>
      <Tour.Progress />
      <Tour.Close />
    </Tour.Header>
    <Tour.Title />
    <Tour.Description />
    <Tour.Footer>
      <Tour.Skip />
      <Tour.Prev />
      <Tour.Next />
    </Tour.Footer>
  </Tour.Popup>
</Tour.Provider>
```

## Composition

<Prose>

`defineTour` lists a tour's steps, and a Server Component may import the definition. `Tour.Provider` wraps the app once and keeps every tour's records. Each step's element registers where it renders: `Tour.Target`, `useTourStep` on a component's own element, or a `data-tour-step` attribute in plain HTML. `Tour.Popup` shows the step on screen, wherever it sits under the Provider, and the parts inside it read that step. `useTour` starts a tour from a control, and `useAutoStartTour` starts it on its own.

</Prose>
