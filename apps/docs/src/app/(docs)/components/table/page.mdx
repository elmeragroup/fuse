<Prose>

`Table.Root` wraps a native `<table>` in a horizontal scroll container. Props and
`className` go to the table; the scroll div is fixed. Header, body, footer, row, head,
cell, and caption are the matching HTML elements. Put `data-state="selected"` on
`Table.Row` when a row model marks it selected — the library never stamps that
attribute.

Inside `Frame.Root` the body restyles itself: separate borders, rounded corner cells,
`bg-background` cells, and an inner hairline. That reshape is selector-driven. There is
no `inFrame` prop.

`VerticalTable` is the facts-sheet layout. `Root` carries `data-variant`. `Header` is a
plain `<h2>` — polymorphic through `render`, not react-aria Heading. `Body` maps a
`data` array to rows first, then renders children. All Body props including `className`
stay on the bordered wrapper.

</Prose>
