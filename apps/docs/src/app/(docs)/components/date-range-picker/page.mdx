## Usage

{/* prettier-ignore */}
```tsx
import { DateRangePickerField } from "@elmeragroup/fuse/date-range-picker";

<DateRangePickerField
  label="Stay"
  defaultValue={{
    start: Temporal.PlainDate.from("2026-10-05"),
    end: Temporal.PlainDate.from("2026-10-09"),
  }}
/>
```
