The dates stack beside the calendar trigger when the field container is narrower than 24rem. Each date keeps its normal density sizing. Inside a flex row the picker takes no width from its content, so it gets only the room its siblings leave. Give it `w-96 shrink-0` there to hold 24rem and keep the dates on one row.

<Prose>

Values are `{ start, end }` ranges of `CalendarDate` objects from `@internationalized/date`, which you install separately; the library does not re-export it.

`onChange` fires only once a range is complete, so a partly typed range reports nothing.

Wrap locale-dependent usage in `UiProviders` so it follows the app locale.

</Prose>
