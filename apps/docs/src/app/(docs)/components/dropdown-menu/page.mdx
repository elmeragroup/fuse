<Prose>

Positioner props (`side`, `align`, `sideOffset`, `alignOffset`) and `container` surface on
both `DropdownMenu.Content` and `DropdownMenu.SubContent`. Content defaults to
`start / 0 / bottom / 4`; SubContent tucks against its trigger at `start / -3 / right / 0`
and renders its own thin popup — it does not wrap Content. The standalone
`DropdownMenu.Portal` part stays exported for advanced composition.

`Item.variant` keeps the value `"destructive"` and emits `data-variant="destructive"` so
existing callers keep working; the classes themselves read `error` tokens.
`LinkItem` is the navigational face — pass `render={<Link href=… />}` for a router link.
Radio items use a check indicator, matching the Funnel face rather than a filled dot.

</Prose>
