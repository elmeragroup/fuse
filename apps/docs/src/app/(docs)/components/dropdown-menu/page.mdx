`DropdownMenu.RadioGroup` is generic over the selected value's string union, so `value` and
`onValueChange` agree by type. Item values are **not** checked against that union:
`DropdownMenu.RadioItem` keeps the primitive's own value type, so a mistyped item value still
compiles.

`DropdownMenu.Label` renders the primitive's group label, so it must sit inside a
`DropdownMenu.Group`; it labels the items of the group it belongs to.
