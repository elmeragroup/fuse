<Prose>

The compound is server-safe: it owns no state, handlers, or browser APIs. `Heading`
renders a plain `<h2>` with the level-2 type classes — not the library `Heading`
component, and with no react-aria import. Other outline levels use `render`. `Root` is a
bare grouping `div`; all layout lives on `Content`.

Term/definition association is structural HTML. Multiple `<dt>`s may share a `<dd>` and
vice versa. Consumers add `aria-labelledby` on `Content` when the heading should name the
list. There is no keyboard behavior or ARIA wiring.

</Prose>
