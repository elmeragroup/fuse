## Usage

{/* prettier-ignore */}
```tsx
import { Command } from "@elmeragroup/fuse/command";

<Command.Root items={["New customer", "Open invoices"]}>
  <Command.Input />
  <Command.Empty />
  <Command.List>
    {(command: string) => <Command.Item key={command} value={command}>{command}</Command.Item>}
  </Command.List>
</Command.Root>
```

## Composition

<Prose>

Every palette starts at `Command.Root`, which holds its state and renders no element. Without a stack of pages, the Root is the search. Pass the actions in `items` and render them through a row function in `Command.List`. With `defaultPages` or `pages`, the Root holds a stack, and each `Command.Page` holds its own search.

Put the parts in `Command.Content` for a dialog that `Command.Trigger` opens. Without `Command.Content` the palette renders no dialog, so place it in a box of your own on the page, or in your own `Dialog.Content`. Place `Command.Status` and `Command.Empty` beside `Command.List`, not inside it, and `Command.Footer` with its key hints after it. An app mounts one Root in its layout, so the palette stays mounted while the user moves between pages.

</Prose>
