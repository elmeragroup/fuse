<Prose>

Values are `CalendarDate` objects from `@internationalized/date`, which you install separately; the library does not re-export it.

Render `DatePicker` inside `UiProviders`, which supplies the app locale it follows. Without a `LocaleProvider` above it, `DatePicker` throws when it mounts.

</Prose>
