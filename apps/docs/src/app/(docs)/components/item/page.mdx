## List semantics

`Item.Group` renders `role="list"`, and an `Item` inside it adopts `role="listitem"`
automatically so the list is never half-announced. The `role` prop overrides that.

</Prose>

## Footer reveal

`mode="hidden"` renders the footer `inert`, so its content is removed from tab order, pointer
events, and the accessibility tree until the mode changes.
