## Usage

{/* prettier-ignore */}
```tsx

<Item.Root>
  <Item.Content>
    <Item.Title>Spot</Item.Title>
    <Item.Description>Hourly price with no lock-in.</Item.Description>
  </Item.Content>
</Item.Root>
```
