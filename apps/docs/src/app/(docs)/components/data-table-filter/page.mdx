## Usage

{/* prettier-ignore */}
```tsx
import { DataTableFilter } from "@elmeragroup/fuse/data-table-filter";

<DataTableFilter.Root table={table} fields={ORDER_FILTERS} timeZone="Europe/Oslo">
  <DataTableFilter.Bar aria-label="Order filters" />
  <DataTableFilter.Content />
  <DataTableFilter.ValueContent />
</DataTableFilter.Root>
```

## Composition

<Prose>

Describe each filterable column once with `defineFilterFields<Row>()` and pass the map to the Root as `fields`. Render `DataTableFilter.Bar`, `DataTableFilter.Content` and `DataTableFilter.ValueContent` as siblings inside the Root. With `manualFiltering`, check untrusted filter JSON on the server with `parseColumnFilters` against the same map, and apply each filter to rows with `matchesFilter`.

</Prose>
