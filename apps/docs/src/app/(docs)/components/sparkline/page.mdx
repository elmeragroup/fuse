<Prose>

The chart entry is a preview. Its names and props can change until Fuse's first stable release. `Sparkline` calls no hook, so a server component renders it with no client JavaScript. A Sparkline is an image with no keyboard stop: its name is the `aria-label` followed by a sentence that names the lowest and highest values, and with `start`, `interval` and `timeZone` their slots.
