<Prose>

`CheckboxCard` is a labeled composite, not a `CheckboxItem` row. It always
renders `Field.Item` → `Card` / `Card.Content` → `Field.Label` plus the checkbox
control. That requires a `Field.Root` ancestor — typically `CheckboxGroup`,
which also supplies the checkbox-group primitive `value` membership needs.
`CheckboxCard` does not create those ancestors.

`title` is required `ReactNode`; native `title` is omitted so that type is not
narrowed to `string`. `description` is a required string. `tags` render as
`Badge` chips above the title and disappear when the array is empty or absent.
`children` sit below the description, still inside the label, so they toggle
the control. `rightContent` sits outside the label and does not.

`variant` is `default` (`bg-card`) or `muted` (`bg-muted`). `isDisabled` fades
the card and disables the primitive — there is no `disabled` pass-through, no
`className`, and no `render` escape hatch. The circle/check-circle indicator is
fixed. Custom indicators belong on `SelectionItem.Shell`'s `control` slot.

</Prose>
