<Prose>

`Tabs.Root` owns the selected value. `Tabs.List` takes `variant`: `"default"` is the
filled pill track, `"line"` is the underline style. `orientation` defaults to
`"horizontal"` and is stamped on Root before hydration so the first paint already
stacks the list above the panels. Arrow keys move and activate tabs; the open panel
has `tabIndex={0}` and composes the shared focus ring. Disabled triggers stay in the
roving-focus sequence but do not activate.

</Prose>
