<Prose>

A vertical separator stretches to the height of its row. For a shorter line in a header, add `data-vertical:h-4 data-vertical:self-auto` and center the row with `items-center`. `h-4 self-center` leaves the line at the top of the row. The separator's own `data-vertical:self-stretch` sorts after `self-center` and wins, and a stretched item with a fixed height aligns to the start of the row.
