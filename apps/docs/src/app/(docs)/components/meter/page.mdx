<Prose>

The composite face is `value`, `minValue` / `maxValue`, `mode`, optional `label` /
`valueLabel`, and `warningLabel` / `successLabel` overrides for the status icons.
There is no `locale` prop — number formatting and dictionary defaults follow
`ElmeraGroupUiProvider`. Mode `"inverted"` flips good/bad colors; it is not a
Tailwind variant. `inverted` and `neutral` never render an icon. There is no
`size` axis: the track is a decorative bar, not a control box.

</Prose>
