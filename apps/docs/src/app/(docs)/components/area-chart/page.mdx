## Threshold colour

<Prose>

A threshold colour splits a series at one value, such as a spot price above and below the period's average. Give the series' config `color` a `threshold` and a role and a legend label for each side. A value above the threshold paints `above`, and a value at or below it paints `below`. The line and the fill change colour where they cross the threshold, a bar paints its own side, and so do the active dot, markers and the tooltip swatch.

The threshold is a number, and Fuse computes none, so pass the same number to a `ReferenceLine` to show where the split lies. The legend lists both sides, while the tooltip, the table and the spoken text keep the series' own label. A threshold follows the series' own values, so it throws `scale-colour-on-stack` on a stacked Line or Area, as a scale does.

</Prose>

## Keyboard

<Prose>

The plot is one tab stop. The legend toggle group and the table's button add one each.

| Where               | Keys                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chart               | ArrowRight and ArrowLeft move one slot. PageDown and PageUp move a tenth of the window's slots, at least one. Home and End go to the window's first and last slot. ArrowDown and ArrowUp move the series focus. Enter and Space select the focused series while a legend toggle group is mounted, and pin the tooltip otherwise. Escape hides the tooltip and keeps focus, and a second Escape passes on. |
| Legend toggle group | Tab enters at the pressed toggle or the first. The arrows move, and Enter or Space presses a toggle. Pressing the pressed toggle clears the selection.                                                                                                                                                                                                                                                    |
| Table               | The table's button and the page buttons are native buttons. The button moves focus to the table, which never joins the Tab order.                                                                                                                                                                                                                                                                         |

</Prose>
