---
lede: >
  A list beside the detail of its open item, which moves into a Sheet over the list where the list has
  too little room for both. Use it in a list-heavy view, such as an inbox, an order queue or an admin
  table.
---

## Usage

{/* prettier-ignore */}
```tsx
import { ListDetail } from "@elmeragroup/fuse/list-detail";

<ListDetail.Root open={open} onOpenChange={setOpen}>
  <ListDetail.List>{rows}</ListDetail.List>
  <ListDetail.Detail aria-label="Order details">
    <ListDetail.Title>Order 1042</ListDetail.Title>
  </ListDetail.Detail>
</ListDetail.Root>
```
