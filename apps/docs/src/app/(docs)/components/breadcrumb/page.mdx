<Prose>

`Breadcrumb.Root` is a localized `<nav>` landmark. The trail is an ordered list;
separators are presentational and omitted from the accessibility tree. There is
no `locale` prop — dictionary defaults follow `ElmeraGroupUiProvider`. Explicit
`aria-label` wins over the `label` prop over the dictionary. `Breadcrumb.Link`
swaps its host through `render` (`useRender` + `state.slot`); there is no `as`
prop. `Breadcrumb.Page` keeps the WAI-ARIA current-page trio on a `<span>`.

</Prose>
