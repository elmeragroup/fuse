<Prose>

`DatePickerField` from `@elmeragroup/fuse/date-picker` is the Temporal replacement for the interim [React Aria DatePicker](/components/date-picker), with its prop names: `label`, `description`, `errorMessage`, `isInvalid`, `isDisabled`, `isReadOnly`, `isRequired`, `value`, `defaultValue`, `onChange`, `minValue`, `maxValue`, `isDateUnavailable`, `granularity`, `hourCycle`, `hideTimeZone`, `firstDayOfWeek`, `presetGroup`, `triggerPlacement`, `size`, `isOpen`, `defaultOpen`, `onOpenChange` and `onBlur`. Its values are `Temporal.PlainDate`, `PlainDateTime` or `ZonedDateTime`, or their ISO text, which a server component passes; `onChange` hands back this runtime's value. Pass the kind as a type argument, `DatePickerField<Temporal.PlainDate>`, when you pass ISO text alone.

Fuse reads `globalThis.Temporal`. Import `@elmeragroup/fuse/temporal-polyfill` once in your app's entry, on the server and in the browser.

Type into the segments as in [DateField](/components/temporal-date-field), or open the calendar with the trigger or Alt+ArrowDown in the field. Focus moves to the selected day, or today, and back when the popup closes. Picking a day commits it and closes the popup.

</Prose>

## Dates and times

With a `PlainDateTime` or `ZonedDateTime` the field edits the time down to `granularity`, and picking a day keeps the value's time and zone. `hourCycle={24}` shows 24 hours, `hideTimeZone` hides a zoned value's zone name, and `timeZone` is the zone an empty zoned picker takes. Until a value names its kind, an empty picker follows changes to `granularity` and `timeZone`, in what it types as in what the calendar picks. With `shouldCloseOnSelect={false}` and no value yet, a picked day is held while the popup stays open and commits at midnight when it closes.

</Prose>

## Presets

`presetGroup` puts a preset pane beside the calendar, normally `DatePicker.Presets` with a `DatePicker.PresetItem` per choice. The pane is a radio group of the presets' keys: map the chosen key to a date and set the picker's value, and the calendar moves to its month. `onValueChange` receives the key and details as the picker's own callbacks do: `reason` `"preset-press"`, the DOM `event`, the preset's radio as `trigger`, and `cancel()`, which keeps the checked preset as it was. `disabled` disables a preset, and `closeOnDoubleClick` closes the popup on a double-click (the interim `isCloseDialogOnDoubleClick`).

</Prose>

## In a form

Inside `Form`, the picker is a Field of the form: its ISO text reaches `onFormSubmit` and native `FormData` under its `name`, a required, incomplete or out-of-bounds value blocks the submit and takes focus on its first segment, and an error the form returns under its `name` shows below it until the value changes.

## Parts and cancelable changes

`DatePicker.Root` holds the value and the open state, with Base UI's names: `value`, `onValueChange`, `open`, `onOpenChange`, `disabled`, `readOnly`, `required`, `invalid`, `render`. Compose `DatePicker.Group` (the field box), `DatePicker.Input`, `DatePicker.Trigger`, `DatePicker.Popup` and `DatePicker.Calendar`, which takes `Calendar`'s parts as children. In a `Field.Root`, its `Field.Label` names the group, the segments, the trigger and the popup. A disabled `Field.Root` or `Field.Set` around the picker disables it whole, the trigger, calendar and presets included, from the server's first render on.

`onValueChange` receives the change's details: its `reason` (`"day-press"`, `"keyboard"`, `"input-change"`, `"input-clear"`, `"input-paste"`), the DOM `event`, the `trigger`, `getValidationError()` and `cancel()`. Canceling a day keeps the value and the popup open; canceling an edit shows the value again in the segments. `onOpenChange` receives Base UI Popover's reasons and the picker's own (`"keyboard"`, `"day-press"`, `"preset-press"`); canceling keeps the popup as it is. React Aria has no equivalent.

</Prose>

## Server rendering

`DatePickerField` holds no state of its own, so a server component renders it with ISO-text props; its parts are client components. Nothing reads the clock while rendering: the calendar marks today from its first client effect.

## Accessibility

- **One group.** The field box is a `group` named by the label. Its segments are named "month, Moving date" (textboxes on iOS), as DateField's.
- **The trigger and the popup.** The trigger is named "Calendar" and the label ("Calendar Moving date"), with `aria-haspopup="dialog"`; the popup is a `dialog` with the same name. Opening it moves focus to the focused day; Escape closes it and returns focus.
- **Presets.** Each preset is a native radio inside its label, so the whole row is the target and the arrow keys move between them.
- **24px targets.** The trigger takes the field's inner square, and the day buttons keep their 36px circles at both densities.
