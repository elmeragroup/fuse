<Prose>

Button sizes every SVG child without a `size-*` class to 16px, and the `xs` and `icon-xs` sizes to 12px. Any
`size-*` class opts out, `size-auto` included; `w-*` and `h-*` on their own do not, because the rule matches
the class name. Mark a leading or trailing icon with `data-icon="inline-start"` or `"inline-end"` so the
button tightens that edge's inset.

An SVG without a `viewBox` clips instead of scaling when the rule forces it to 16px. Logos that go through
SVGR often arrive that way, because SVGO's default `removeViewBox` strips the attribute. Give such an icon
`size-auto` to keep its intrinsic `width` and `height`, or restore the `viewBox` so it scales.

</Prose>

<Prose>

Labels keep to one line and the size's fixed height. To let a long call to action wrap on a narrow
screen, override the size through `className`: `h-auto` and `min-h-(--control-h-md)` make the height
a minimum, `py-[calc((var(--control-h-md)-1lh)/2-1px)]` keeps a one-line button exactly as tall as a
plain one (half the height minus one line and the 1px border), `whitespace-normal` lets the text break
and `text-center` centres the lines. Every size class is an unprefixed utility, so these replace the
recipe's through `cn`. Use the `--control-h-*` token of the size in use (`xs`, `sm`, `md` for the default
size, `lg`); the tokens follow density, so the height stays exact at both.

</Prose>
