## Usage

{/* prettier-ignore */}
```tsx
import { Field } from "@elmeragroup/fuse/field";
import { Input } from "@elmeragroup/fuse/input";

<Field.Root>
  <Field.Label>Email</Field.Label>
  <Input type="email" />
  <Field.Error />
  <Field.Description>Work address preferred.</Field.Description>
</Field.Root>
```

## Composition

<Prose>

Put one control in a `Field.Root`, with the `Field.Label`, `Field.Error` and `Field.Description` that belong to it. The root points the label at the control and adds the error and description to the control's `aria-describedby`. Fuse's controls, such as `Input` and `Checkbox`, take this wiring from the root around them. A `Textarea` takes it through `Field.Control`'s `render`. The field components, such as `TextField` and `NumberField`, render the root and its parts themselves, so build a field from parts only for a control that has no field component, such as an `InputGroup`. `Field.Set` groups fields under a `Field.Legend`, and `Field.Group` stacks them.

</Prose>
