<Prose>

`RangeCalendar` lives at `@elmeragroup/ui/react-aria/range-calendar`. The
`react-aria/` prefix is the quarantine marker: this module is replaced alongside
`Calendar` when a base-ui range calendar ships, and the bare path is reserved for
that successor. The composite is a single month — `visibleDuration` is omitted —
and its `value`, `defaultValue` and `onChange` speak the RAC range shape,
`{ start, end }`. Remaining RAC RangeCalendar props (`focusedValue`, `minValue` /
`maxValue`, `isDateUnavailable`, `allowsNonContiguousRanges`, …) pass through, and
`errorMessage` takes any `ReactNode`.

The month row and the weekday row are `CalendarHeader` and `CalendarGridHeader`
from `@elmeragroup/ui/react-aria/calendar` — the same parts `Calendar` renders, so
navigation and RTL behaviour match. Unlike `Calendar`, the root carries no card
surface: standalone it renders borderless, and the picker dialog supplies the
chrome. Wrap locale-dependent usage in `UiProviders` from
`@elmeragroup/ui/react-aria/ui-providers`.

Keyboard range selection anchors on Enter or Space, extends while the arrow keys
move the focused day, and commits on the second Enter or Space. Escape cancels an
in-progress selection and restores the previous range.

</Prose>
