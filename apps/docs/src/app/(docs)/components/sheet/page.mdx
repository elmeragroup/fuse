  An edge-anchored overlay with swipe-to-dismiss. `Sheet.Root` owns `side` (default
  `right`) and the swipe direction coupled to that edge; `Sheet.Content` sizes the panel,
  ships the corner close button, and portals into the nearest `ThemeScope`.

<Prose>

`Sheet` is a drawer, not a centred dialog: it sits on an edge, follows the finger while
you swipe, and uses transitions rather than keyframes so the same transform can serve
enter, exit, and swipe-follow. `size` only applies to left and right panels from the
`sm` breakpoint up — top and bottom sheets, and every sheet below `sm`, are full width.

The built-in close button is the same helper Dialog uses. Pass `closeLabel` to override
the locale dictionary (`sheet.close`).

</Prose>
