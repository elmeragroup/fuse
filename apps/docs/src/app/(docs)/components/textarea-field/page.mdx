<Prose>

The composite face is `isDisabled` / `isInvalid` / `isRequired`, `onChange(value)`, and
`errorMessage` as a `ReactNode`. Supplying `value` makes the field controlled;
`defaultValue` (or neither) is uncontrolled. `maxLength` is forwarded natively and
drives the `current/max` counter. There is no own recipe — `min-h-16` comes from the
`Textarea` primitive.

</Prose>
