<Prose>

`Calendar` lives at `@elmeragroup/ui/react-aria/calendar`. The `react-aria/`
prefix is the quarantine marker: this module is replaced when a base-ui calendar
ships, and the bare path is reserved for that successor. The composite is a
single month — `visibleDuration` is omitted — with optional `errorMessage` as a
`ReactNode`. Remaining RAC Calendar props (`value`, `defaultValue`, `onChange`,
`focusedValue`, `minValue` / `maxValue`, `isDateUnavailable`, …) pass through.

`CalendarHeader` and `CalendarGridHeader` are public reuse seams for
RangeCalendar and custom bodies. Navigation icons flip in RTL through
`useLocale()`. Wrap locale-dependent usage in `UiProviders` from
`@elmeragroup/ui/react-aria/ui-providers`.

Values are `@internationalized/date` objects — `CalendarDate` and friends — not
`Date`. That package is a direct install for consumers (`pnpm add
@internationalized/date`): the demos below import it by name, and the copy shipped
inside `@elmeragroup/ui` is an implementation detail of the quarantined tier, not a
re-export.

</Prose>
