<Prose>

Thin styled wrappers over `@base-ui/react/avatar` — no added state and no size axis.
Override the default `size-8` with `className`. When adjacent text names the user,
`Avatar.Image` should use `alt=""`; give the root an `aria-label` when the fallback
initials would otherwise be the only name.

The fallback surface uses `bg-muted` / `text-muted-foreground`. There is no library
API for stacking — overlapping groups are consumer classes.

</Prose>
