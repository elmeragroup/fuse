<Prose>

The chart entry is a preview. Its names and props can change until Fuse's first stable release. `LineChart` is the same component as `Chart`. A line draws in SVG once the browser measures the plot, and every vertex lands on the pixel column the crosshair takes at its slot, so a dot, a marker and the active dot sit on the line at any width and zoom.

</Prose>

## Curves and looks

<Prose>

`curve` picks a d3 curve. `"step-after"` and `"step-before"` run each reading across its whole slot, so the last hour of a day keeps its run, and they need the default band scale. `variant="dashed"` dashes a target, `"quiet"` draws a faint reference such as last year, and `"flowing"` runs its dashes along the line, which reduced motion stops.

</Prose>

## Readings and quality

<Prose>

A missing reading leaves a gap, and a reading between two gaps draws a dot. Config `missing: "connect"` bridges a gap with a dashed segment instead, because a bridge is no measurement. The segments that touch an estimated reading and the tail from config `projectedFrom` draw dashed too.

</Prose>

## Updates and large data

<Prose>

A data update moves the line to its new readings, with its dots and markers on it. An update that appends a reading and drops the first slides the line along the axis, one that shares no slot pairs the old and new readings by position, and any other change of slots crossfades. Above 2,000 slots in the window, the line draws the lowest, highest, first and last reading of each pixel column, so every spike stays.

</Prose>

## Keyboard

<Prose>

The plot is one tab stop. The legend toggle group and the table's button add one each.

| Where               | Keys                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chart               | ArrowRight and ArrowLeft move one slot. PageDown and PageUp move a tenth of the window's slots, at least one. Home and End go to the window's first and last slot. ArrowDown and ArrowUp move the series focus. Enter and Space select the focused series while a legend toggle group is mounted, and pin the tooltip otherwise. Escape hides the tooltip and keeps focus, and a second Escape passes on. |
| Legend toggle group | Tab enters at the pressed toggle or the first. The arrows move, and Enter or Space presses a toggle. Pressing the pressed toggle clears the selection.                                                                                                                                                                                                                                                    |
| Table               | The table's button and the page buttons are native buttons. The button moves focus to the table, which never joins the Tab order.                                                                                                                                                                                                                                                                         |

</Prose>
