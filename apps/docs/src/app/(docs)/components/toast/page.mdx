<Prose>

There is no sonner `Toaster` / `toast.*` shim. Call `toastManager.add({ description, type })`
for success, error, info, warning, or a plain neutral toast; `promise()` walks
loading → success or loading → error. Status `-soft` chrome is always on, and every toast
ships a locale-labeled close button.

`container` on `Toast.Viewport` portals into the nearest `ThemeScope` (or an explicit
element). The viewport waits while that target is still `null` rather than escaping to
`document.body`. Positioner and Arrow stay unexported — stacked toasts only.

Locale comes from `ElmeraGroupUiProvider` only. Close copy defaults to `toast.close`;
`label` overrides it. `priority` is type-aware (error is high, everything else is low)
unless the caller sets it.

</Prose>
