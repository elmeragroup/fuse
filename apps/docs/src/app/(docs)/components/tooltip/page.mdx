<ComponentIntro slug="tooltip" />

<Prose>

Positioner props (`side`, `align`, `sideOffset`, `alignOffset`) surface on
`Tooltip.Content`. Portal, Positioner and Popup stay unexported — `container` on Content
is the only portal-control surface, and it defaults to the nearest `ThemeScope`. The
arrow is always rendered; that is deliberate and is not unified with Popover's opt-in
`showArrow`.

`Tooltip.Provider` defaults `delay` to `0`. Setting `delay` on `Tooltip.Root` wraps that
tooltip in a nested scoped provider, so it forms its own group and no longer
participates in the outer Provider's shared delay or skip-delay hand-off.

</Prose>
