<Prose>

Use a slider when the bounds are known and a rough position is enough. For an exact
number, pair it with a NumberField that shares its value, as the label-less demo does.

Pass an array of two or more numbers as `value` or `defaultValue` for a range. Each entry
renders a thumb, and `onChange` reports an array of the same length. A range names its
thumbs "minimum" and "maximum" in the provider's locale, joined to `label` or `aria-label`.
Pass `thumbLabels` to name them yourself.

A vertical slider fills its parent's height below the label row, so give the parent a
height, as the vertical demo does.

`formatOptions` formats the value that `showValue` puts in the label row and the value a
screen reader announces for each thumb.

</Prose>
