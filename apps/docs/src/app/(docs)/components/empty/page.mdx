<Prose>

Empty has no base-ui primitive behind it. `Title` is a `div`, not a heading — empty states
are transient placeholders and must not perturb the page outline. `Description` is a real
`p` so inline links remain ordinary tab stops. The frame and media recipes stay
module-private.

Actions belong in `Empty.Content`; the compound adds no focus management, roles, or live
region. If the empty state replaces async results, the consumer owns the `aria-live`
announcement.

</Prose>
