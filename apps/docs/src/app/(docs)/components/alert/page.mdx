<Prose>

`Alert.Root` is a server composite over `Item` (`variant="outline"` `size="sm"`) with an
explicit `role="alert"`. The status icon is rendered automatically inside `Item.Media`
and is decorative (`aria-hidden`). `Alert.Title` is its own `h3` by default — pass
`level` to fit an existing outline. `onAction` is a forwarded consumer handler, so the
client boundary sits at the caller, not in this module. The `destructive` variant value
is kept; its classes use `error*` tokens.

</Prose>
