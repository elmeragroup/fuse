<Prose>

The wrapper is a `div` with `role="status"` and constant `p-4` centering. `size` only
changes the icon (`default` through `xl`); it is not a density rung. `loaderVariants` is
public from this same entry so other pending surfaces can borrow the recipe without wrapping
the component. There is no baked English `aria-label` — pass a translated name, as the
inline demo does with Norwegian _Laster_.
