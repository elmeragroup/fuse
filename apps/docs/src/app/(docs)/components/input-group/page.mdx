---
title: InputGroup
lede: >
  A structural primitive that joins a control with addons — icons, text, buttons, a
  keyboard hint — into one bordered group that owns the focus ring for the whole cluster.
---

<Prose>

The group is the focus-ring owner: the nested control's own ring is neutralised so a
keyboard user sees one ring around the cluster, not two.

</Prose>
