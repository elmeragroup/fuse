<Prose>

Values are `CalendarDate` objects from `@internationalized/date`, which you install separately; the library does not re-export it.

`DateInput` is the segment row on its own, for custom field compositions.

Wrap locale-dependent usage in `UiProviders` so it follows the app locale.
