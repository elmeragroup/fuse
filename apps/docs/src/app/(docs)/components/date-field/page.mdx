<Prose>

`DateField` lives at `@elmeragroup/ui/react-aria/date-field`. The `react-aria/`
prefix is the quarantine marker: this module is replaced when base-ui ships a
date field, and the bare path is reserved for that successor. The composite face
is optional `label` / `description`, `errorMessage` as a `ReactNode` or
`(ValidationResult) => ReactNode`, and `shouldForceLeadingZeros` defaulting to
`true`. Remaining RAC DateField props (`value`, `granularity`, `hourCycle`,
`minValue` / `maxValue`, `isDisabled`, `isReadOnly`, …) pass through.

`DateInput` is public and reusable. It always renders RAC date segments — it
does not accept `children` — and keeps `slot` for start/end range pickers. Wrap
locale-dependent usage in `UiProviders` from `@elmeragroup/ui/react-aria/ui-providers`.

Values are `@internationalized/date` objects — `CalendarDate` and friends — not
`Date`. That package is a direct install for consumers (`pnpm add
@internationalized/date`): the demos below import it by name, and the copy shipped
inside `@elmeragroup/ui` is an implementation detail of the quarantined tier, not a
re-export.
