## Usage

{/* prettier-ignore */}
```tsx
import { tableFeatures } from "@tanstack/react-table";
import { createFuseTableHook } from "@elmeragroup/fuse/data-table";

const { useAppTable: useFuseTable } = createFuseTableHook({ features: tableFeatures({}) });

const table = useFuseTable({ columns, data });

<table.AppTable>
  <table.Content aria-label="Invoices" />
</table.AppTable>
```

## Composition

<Prose>

Install `@tanstack/react-table` 9.2 or later beside Fuse. `createFuseTableHook` registers Fuse's parts on the table, the header and the cell, such as `table.Content`, `header.SortButton` and `cell.NumberCell`, each only when its feature is in `features`: `table.Pagination` needs `rowPaginationFeature`. Render them inside `<table.AppTable>`. A `cellComponents` entry under a Fuse cell's name replaces that cell and its props, and `selectColumn` and `actionsColumn` build a selection column and a row-actions column. Without the hook, the plain `DataTable.*` parts take an explicit `table`, `column`, `row` or `value` from TanStack's `useTable`.

</Prose>
