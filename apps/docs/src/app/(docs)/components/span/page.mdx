<Prose>

Span is the inline sibling of Text: the same recipe surface, with `leading` defaulting to
`snug` instead of `relaxed`. `spanVariants` is public from this entry and extends
`textVariants` — it does not redeclare colour or align maps. `align` is a first-class prop
(`left`, `center`, `right`, `justify`). `weight="bold"` renders `font-medium`, matching
the inherited body-copy cap.

There is no `elementType` prop: the host is always a `span` unless `render` replaces it.
The RAC `slot` prop is gone. Description labelling now comes from the field family's own
Description part.

</Prose>
