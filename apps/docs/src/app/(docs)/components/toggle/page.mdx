<Prose>

`pressed`, `defaultPressed`, and `onPressedChange` pass through to the primitive. Icon-only
usage needs a consumer-supplied `aria-label`; tag icon children with
`data-icon="inline-start"` or `data-icon="inline-end"` to tighten padding on that side.
