<Prose>

`Focusable` and `useFocusable` live at `@elmeragroup/ui/react-aria/focusable`.
The `react-aria/` prefix is the quarantine marker: this is the tier's only
consumer of the `react-aria` hooks package, and the bare path is reserved for a
successor that will not need a focus-cloning wrapper. `Focusable` clones focus
and hover onto its single child. `useFocusable` returns `focusableProps` to
spread onto a custom element. `FocusableOptions` is the re-exported options
type. Treat the export as migration debt — it dies with the react-aria tier,
because base-ui overlay triggers accept arbitrary render targets.

</Prose>
