<Prose>

`Pagination.Root` is a localized `<nav>` landmark. Pages live in a list;
`Pagination.Link` borrows `buttonVariants` so the current page reads as outline
and the others as ghost. There is no `locale` prop — dictionary defaults follow
`ElmeraGroupUiProvider`. Explicit `aria-label` wins over the `label` prop over
the dictionary. Previous and Next wrap `Link` at `size="default"`; numbered
links default to `size="icon"`.

</Prose>
