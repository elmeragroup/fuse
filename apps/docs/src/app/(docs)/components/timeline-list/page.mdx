<Prose>

The compound is server-safe: it owns no state, handlers, or browser APIs. `Title` renders
the client `Heading` without flipping this module to `"use client"`. `Time` always emits
an ISO `dateTime` from a `Date` or string; invalid values throw
`RangeError("TimelineList.Time received an invalid date")`. Links and actions belong in
consumer content inside `Description` — TimelineList itself has no interactivity.

The recipe is module-private. The connecting line is `Item::before` on every non-last
item, so consumers must not interleave non-Item children.

</Prose>
