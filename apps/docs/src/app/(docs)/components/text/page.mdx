<ComponentIntro slug="text" />

<Prose>

`elementType` defaults to `"p"` and stays beside `render` so existing `"span"` / `"div"`
call sites keep working. `align` is a first-class prop (`left`, `center`, `right`,
`justify`) — not a className-only axis. `weight="bold"` renders `font-medium`: body copy
is capped at medium, matching the ref.

The RAC `slot` prop is gone. Description labelling now comes from the field family's
own Description part.

</Prose>
