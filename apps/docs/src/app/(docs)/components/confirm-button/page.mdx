<Prose>

The first press arms the button (`data-armed`, armed styles, label swap, and a
polite live announcement). The second press disarms and fires `onConfirm` once.
`Escape` and blur cancel the armed state without confirming. Supply a string
`armedChildren` or `armedAriaLabel` so the escalation is announced. There is no
size axis — density comes from Button.

</Prose>
