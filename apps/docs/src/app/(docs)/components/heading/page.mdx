---
title: Heading
lede: >
  A typography primitive. Renders a plain `h1`–`h6`; `level` owns the document outline,
  `size` owns the type scale, and `render` swaps the element through base-ui `useRender`.

<Prose>

`level` defaults to `2` and maps to an auto size (`1` → `2xl`, `2` → `lg`, else `default`)
unless `size` is set explicitly. `headingVariants` is public from the same entry so other
surfaces can borrow the type scale without wrapping this component. Card titles stay on
card.md's `text-{size}` mapping — they do not consume this recipe.

</Prose>
